# 生图提示词模板

交付前替换下列占位内容并注明版本。结构和连接优先于风格。构图必须为关键路径和讲解保留足够面积，不能将决定原理理解的入口、出口或驱动关系压缩为难辨附图。复杂设备聚焦关键过程，必要时组合主图与局部剖面。

```text
用途：用于制作设备原理交互 HTML 的视觉参考。
设备与范围：[设备、型号或通用示意、演示重点]。
必须展示：[部件与可辨识特征]。
结构与连接：[相对位置、连接起止、入口出口、传动关系]。
原理表达：[当前阶段、运动方向、必要路径]。
视角与剖切：[视角、剖面、透明范围，确保关键结构可见]。
视觉风格：[背景、配色、材质、轮廓、光照、层次]。
精细程度：[确认等级、保留细节、允许简化项]。
构图：[画幅、主体占比、说明区留白]。
标注：[少量编号或无文字，中文名称由 HTML 添加]。
避免：[针对此设备的错误连接、遮挡、反向箭头、凭空增加的零件]。
```

有多个视图时说明各视图承担的问题、共同部件和观察方向；最终对应标签由 HTML 添加。箭头容易出错时可生无箭头结构图，在 HTML 中按已核验原理绘制，不能因此跳过结构审核。

三维参考图不能替代精确建模数据。可建议补充视角，但不把不同结构的候选图当成可靠多视图。

修订时提供问题、修改摘要及完整新提示词，保留用户选定风格。不要假设外部生图工具支持图像参考。用户未要求代为生图时不调用生图服务。
