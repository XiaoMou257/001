# HTML 实现

先按 [principle-explanation.md](principle-explanation.md) 建立讲解方案，布局与动画服务于路径和因果，不以装饰性运动替代过程演示。

先按 [fixed-layout.md](fixed-layout.md) 使用固定五区页面结构。设备更换或 2D/3D 切换只改变演示内容及相关控件含义，主题栏、说明栏、演示区和两层底部控制保持同一结构。

提取设备主体与功能色、线条、材质、阴影、视角和构图。保留可辨认特征，必要时调整对比度。功能色含义一致，不承诺从单图像素级还原任意三维视角。

## 项目与技术选型

按演示需求选择项目，不将下列项目全部引入页面：

- **2D 默认：原生 SVG + JavaScript。** 用 SVG 分组、路径及可选部件表达剖面和介质流向，HTML 承载文字和控件；路径动画可用浏览器原生 SVG API。只有大量粒子确有需要时再使用 Canvas。
- **2D 图形复用：[SVG.js](https://github.com/svgdotjs/svg.js)。** 当多套设备图需要重复创建、更新和操作 SVG 元素，或原生 DOM 代码明显繁琐时采用；简单单页演示不为使用库而引入构建步骤。
- **3D 设备演示：[Three.js](https://github.com/mrdoob/three.js)。** 需要可旋转设备、内部结构、透明或剖切视图时使用；建立部件几何、枢轴、层级与材质，提供必要的旋转、缩放和视角复位。透明、剖切、隐藏不能使关键部件不可辨。
- **教学交互参考：[LearnChemE](https://github.com/LearnChemE/LearnChemE.github.io)。** 参考与任务相关的分步讲解、参数控制和过程可视化方式，不把整个项目当作设备页面模板。
- **复杂仿真参考：[PhET example-sim](https://github.com/phetsims/example-sim)。** 仅在多状态、强交互的仿真确有需要时参考其状态与反馈组织；普通单页原理动画不引入整套框架。

借鉴交互思路与复用代码、素材是两回事；复用前核对相应项目及文件的许可。离线交付时将实际使用的库和资源保存在本地，并验证断网运行。

混合视图共享状态，三维部件与二维流程同步高亮。遵守工作目录规则，适用且可用时使用前端和浏览器测试技能，不强依赖特定专有工具。

统一状态驱动姿态、路径、标签和文字。定义开始、暂停、继续、复位和阶段切换行为。按时间差推进，避免帧率影响速度；页面不可见时适当暂停。

基础交互为开始/暂停、复位、分步讲解、部件信息和标签显隐。适合多步阅读时提供可关闭的自动讲解；手动选步骤后停止自动切换，暂停同步冻结动画和讲解计时。单阶段设备不强加无意义步骤。拆解、透明、调速与异常工况按需提供。无模型与参数依据时只演示定性关系，不输出伪精确数据；动画速度标注清楚。

默认支持电脑端鼠标选中、键盘焦点和清楚按钮名称。颜色配合文字或箭头，尊重减少动画偏好并始终提供暂停。仅在用户明确要求手机端时，增加触摸交互与移动窄屏布局。

单文件或资源目录按需求选择。离线时打包库、模型、图片和字体，不暗中依赖 CDN；下载遵守环境权限。说明 file:// 能否运行，需服务器时提供启动命令。

外部标签按文本插入，不使用未经处理的 HTML。不附加统计上报或无关请求，仅交付实际使用的资源。
