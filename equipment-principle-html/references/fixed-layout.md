# 用户指定的固定 HTML 结构

用户明确要求以后设备原理 HTML 沿用“活塞式压缩机.html”的界面结构，按设备及用户选择替换 2D/3D 动画。固定结构是用户偏好，不是从单个案例推导出的通用设计规则；用户后续明确要求其他布局时可覆盖。

原始参考：D:\AI\yzj workspace\冷水机组\活塞式压缩机.html。
技能内可移植起点：[equipment-demo-shell.html](../assets/equipment-demo-shell.html)。已提取原始框架及 CSS，不依赖原始路径继续存在，也不把压缩机的三维库及模型绑定到所有设备。

## 保留的五个区域

| 区域 | 固定职责 | 可替换的设备内容 |
| --- | --- | --- |
| header / mode-tabs | 顶部名称、主题页签、运行状态 | 设备名称、主题、类型说明 |
| principle-panel | 左侧原理说明、状态和小图表 | 因果解释、运行前提、工作状态、流程或有依据的图表 |
| viewport | 中央大面积动画区与右侧视图工具 | SVG/Canvas 2D 或 WebGL 3D，以及必要多视图 |
| transport | 底部播放、单步、复位、进度和速度 | 角度、时间或过程进度；选择与设备相符的控制含义 |
| toolbar | 最底部图例、显隐、观察部位、视图、标注、导出、全屏 | 图例名称、局部观察对象、2D/3D 视图选项 |

桌面基准为 1600×1000：顶部 84 px，左栏 292 px，播放区 84 px，底栏 58 px，其余高度给演示区。保留浅灰白、低饱和绿的界面风格、细分隔线和紧凑工业软件排版。对应 CSS 已内嵌在模板中；大屏及低高度规则沿用模板。必要时提高正文可读性，不能重做成大标题长滚动文章或图卡网格。

默认仅面向电脑端，不为手机或移动窄屏重新排布五区结构。只有用户明确要求手机端时，才在保留五区功能的前提下纵向重排、放大局部并验证可读性；不要将桌面最小宽度直接照搬后声称已适配手机。

## 内容适配不等于改布局

- 压缩机的气阀状态、p-V 图、曲轴角度仅适用于该设备。离心泵可用入口到出口的路径、驱动链和叶轮角度替代，仍留在相同区域。
- 3D 视图用轴测、正视、侧视和旋转；2D 视图用正面、轴向、局部等有意义的选项，支持缩放与复位，不用无意义透视按钮冒充三维。
- 页面文字与状态随设备改变，但布局、控件分区和交互约定保持一致。无需为了保留图表位置编造压力、效率或其他读数。
- 使用参考图时，图像风格应用于中央设备演示；外层页面结构仍以固定模板为准。新参考图不自动授权重做整个界面。

## 使用模板

复制资源到任务目录，替换所有 {{...}} 内容槽位，按设备接入渲染和统一状态。模板是生成源，不是已经完成的演示；交付页中不得残留占位符和无实现的按钮。

DEVICE_SCRIPT 必须实现所呈现的控制：开始/暂停、单步、复位、拖动进度、速度、主题、视图、缩放、部件标注和输出。没有合理用途的设备专用控件可以在原分区内做等效替换，不能照搬错误含义。

实现图标时使用内嵌 SVG 或本地依赖。离线交付不得因模板而重新引入 CDN。3D 依赖只在该任务需要时打包。

## 验证

截图对照五区位置、比例、主题和工具分布。桌面可读性通过后再检查目标尺寸。逐项操作所交付控件，确认动画、说明、读数及图表由同一状态驱动；暂停不能只停某一个部件。

功能测试通过仍需“路径—原因—画面证据”的讲解清晰度验收。模板一致不能替代原理清晰。
